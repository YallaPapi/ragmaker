# Simple RAGMaker Desktop Application

A simple, visible desktop RAG (Retrieval-Augmented Generation) application built with Electron.

## Features

- **Visible Desktop Window**: Clean, modern interface that appears immediately
- **File Upload**: Drag & drop or click to upload text documents (TXT, MD, PDF, DOCX)
- **Chat Interface**: Ask questions about your uploaded documents
- **Basic RAG**: Search through document content and provide relevant answers
- **Professional UI**: Modern gradient design with smooth animations

## Quick Start

### Run the Application
```bash
cd "C:\Users\stuar\Desktop\Projects\ragmaker\simple-ragmaker"
npm start
```

### Build Executable
```bash
npm run build
```

The executable will be created in the `dist` folder.

## How to Use

1. **Launch**: Double-click the app or run `npm start`
2. **Upload Documents**: Click "Select Files" or drag & drop documents
3. **Ask Questions**: Type questions about your documents in the chat
4. **Get Answers**: The RAG system will search and provide relevant information

## Technical Details

- **Framework**: Electron (desktop app)
- **UI**: HTML/CSS/JavaScript with modern styling
- **RAG Implementation**: Simple keyword-based document search
- **File Support**: Text-based documents
- **Window**: 1200x800 pixels, resizable
